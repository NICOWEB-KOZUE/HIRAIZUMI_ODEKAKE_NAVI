1. 行き先を選ぶ画面（大カテゴリ）
目的: 大まかな目的（病院、買い物など）を選んでもらう

部品と並び順:

小さいタイトル文字: 「どこから出かけますか？」

出発地のボタン: 「自宅（バス停：長島体育館）」

（「自宅」には画面0で選んだバス停の名前を出す。最初から「自宅」が選ばれているので、ふだんは押さなくてよい）

（出発地ごとの考え方）
- 自宅: 自宅のバス停からコミュニティバスに乗る

　バス停を変更する　から出発地を変更できる

タイトル文字: 「どこへ行きたいですか？」

ボタン（6つ縦並び）: 「病院」「買い物」「役場」「郵便局・銀行」「温泉」「平泉駅」


2. 詳細な行き先を選ぶ画面
目的: 選択した大カテゴリに合わせて、具体的な目的地を選んでもらう

部品と並び順:

タイトル文字: 「行き先を選んでください」

ボタンまたは一覧（縦並び）:

（病院を選んだ場合）町内の医院を上に、町外の病院を下に並べる

「ひらいずみ内科クリニック」「平泉歯科診療所」「ささき歯科」「あすか薬局」

「磐井病院（一関）」「岩手病院（一関）」「胆沢病院（水沢）」「水沢病院（水沢）」

「一関駅周辺の医院」「山目周辺の医院」「水沢駅周辺の医院」

（エリアを選んだ場合は、一関駅前・山目駅前・水沢駅に何時に着くかと、帰りに何時の電車・バスに乗ればコミュニティバスに間に合うかを出す。駅から医院までは本人が知っている前提）

（買い物を選んだ場合）「ジョイス 平泉店」「道の駅 平泉（産直）」

（郵便局・銀行を選んだ場合）「平泉郵便局」「岩手銀行 平泉支店」

（役場・温泉・平泉駅を選んだ場合）行き先が1か所なので、この画面は飛ばして時間を選ぶ画面へ進む（役場は「平泉町役場」、温泉は「悠久の湯 平泉温泉」）

3. 時間を選ぶ画面
目的: いつ行きたいか（日にちと時間帯）を指定してもらう

部品と並び順:

タイトル文字: 「いつ行きたいですか？」

日にちのボタン（大きく縦並び）: 「今日（水）」「明日（木）」「あさって（金）」「それ以外の日」

（曜日は開いた日に合わせて変わる。「それ以外の日」を押すとスマホの日付選択が出る）

（コミュニティバスが運行しない日は、ボタンに「この日は運行なし」と表示する。乗るバス停のルートの運行曜日で判定する。水・土・日・祝日はどのルートも運行なし）

（町内の行き先で、行き先のバス停に止まる便が一部の曜日だけのときは、日にちのボタンの上に案内を出す。例: 「バス停『道の駅』で直接降りられる便: 月曜の午前の便（10:02 着）／次に直接行ける日: 10月19日（月）／ほかの日は平泉駅で降りて歩きます（ゆっくり歩いて約20分）」。直接行ける日のボタンには「道の駅まで直接行けます」と出し、最初からその日を選んでおく。結果画面でも、直接行けない日を選んだときは同じ案内を出す）

時間帯のボタン（縦並び）: 「午前中に行く」「午後に行く」（見出しは「時間帯を選ぶと、行き方が出ます」、ボタン右端に「›」。押すとそのまま結果へ進む）

（コミュニティバスは午前便と午後便が1本ずつなので、「午前中」「午後」で乗る便を決める）

4. 利用できる方法と連絡先を見る画面（結果）
目的: 選んだ条件に合わせて、使える移動手段と次のアクションを案内する

部品と並び順:

タイトル文字: 「利用できる移動手段」

リスト（複数）:

（コミュニティバスの案内・利用者登録・電話は画面0にあるので、ここには出さない。運賃は乗り換え候補の中に出す）

「平泉巡回バス　るんるん」（土日祝日のみの季節運行なので、選んだ日が運行日のときだけ出す）

「路線バス（岩手県交通 一関平泉線: 一関駅前・山目・毛越寺・平泉駅前・中尊寺・衣川の瀬原）」（平泉駅前から一関駅前まで370円）

「鉄道（JR東北本線・平泉駅）」（平泉から一ノ関まで210円、水沢まで330円）

「タクシー」（運賃は会社に電話で確認）

（行き先が一関市・奥州市の場合は、時刻つきの乗り換え候補を一番上に出す）

乗り換え候補（行きと帰りをセットで表示）:

（出発地が自宅以外のときは、行きをその場所から始める。例: 出発地が平泉駅なら「行き: 平泉 10:20 → 一ノ関 10:27」）

「行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:20 → 一ノ関 10:27」

「帰り: 一ノ関 12:46 → 平泉 12:54 → 平泉駅 13:35 のバス → 長島体育館 13:49」

「一関にいられる時間: 約2時間20分」

（JR の候補と、路線バス（一関平泉線）の候補を並べて出す。奥州市衣川へは路線バス、水沢へは JR の候補を出す）

（帰りのバスに間に合わない日は「帰りはタクシーをおすすめします」と出す）

（家のバス停に帰るバスがなくても、その日に走る別のルートのコミュニティバスが家の近くのバス停に止まるなら、「帰りは別のルートのバスで帰る」の候補も出す。近いバス停は、家のルートでバスで3分以内に通り、別のルートも止まるバス停。例: 長島東西ルートの境田に住む人は、火・金に長島南北ルートで開田碑前まで帰れる）

（家のバス停か近くのバス停に東磐交通 一関線が止まるなら、平日は路線バスで帰る候補も出す。町の中の行き先からは「帰りは一関駅をまわって、路線バスで帰る」として、平泉駅から JR か一関平泉線で一関駅へ行き、一関線に乗りかえる。一関の行き先からは一関駅で一関線に乗りかえる。近いバス停の決め方はコミュニティバスと同じ）

（帰りに乗るコミュニティバスがその日最後の便のときは、帰りの欄に「帰りのバスはこの1本だけです。もっとゆっくりしたいときは、帰りはタクシーになります」と出す）

（病院の場合は、駅から病院までのバスも含めて出す。病院に着く時刻が受付締め切りを過ぎるときは「受付に間に合いません」と出し、駅からタクシーを使う候補を上に出す）

（町内の行き先の場合は、着く時刻に開いているかを出す。例: 「悠久の湯は 10:00 から。午後の便をおすすめします」）

（駅やバス停から歩く時間は、高齢者がゆっくり歩いた場合の時間で出す。ふつうの「徒歩○分」の1.5倍（切り上げ）とし、受付に間に合うかの判定にもこの時間を使う。例: 「岩手病院前から歩いて約3分（ゆっくり歩いた場合）」）

（乗り換え候補には、行きと帰りそれぞれの運賃の合計も出す。例: 「行き 410円（バス200円 + JR 210円）」。運賃は `docs/timetable.md` の「運賃」）

（時刻のもとになるデータは `docs/timetable.md`）

ボタン（各手段ごと）: 「時刻表を見る」、タクシーだけ「電話する」（予約が必要な手段はないので、予約ページへのボタンは置かない）

いっしょに出かける犬（全部の画面に出す）
目的: 使っていて楽しく、また出かけたくなるようにする

どの画面にも:

画面の下に犬の絵だけを出す。ふだんの画面では犬はしゃべらない（吹き出しは出さない）

（画面の文字はこれまでのタイトルやボタンの言葉のままにする。犬の口調などに言いかえると、分かりにくくなる人がいるため）

結果画面（画面4）の乗り換え候補の上に「おでかけの道のり」:

横1列に、乗りものの絵を順番に並べる。例: 🏠 → 🚌 → 🚃 → 🚌 → 🏥

犬が左（家）から右（行き先）へ、ゆっくり歩いて移動する。行き先に着いたら止まる

犬がしゃべるのは出発と到着の2回だけ（ふつうのことばで短く。「〜ワン」などの口調にはしない）:

- 出発（歩き始めるとき）: 「いっしょに出かけましょう」
- 到着（行き先で止まったとき）: 「岩手病院に着きました」（行き先の名前を入れる）

作り方のメモ:

- 犬の動きは CSS のアニメーションだけで作る（JavaScript もスマホのセンサーも使わない）
- 乗りものの並びは、乗り換え候補を作るときに Python で一緒に作って HTML に渡す（例: ["home", "bus", "train", "bus", "hospital"]）
- 犬の絵は、まずは絵文字（🐕）で作る。余裕があればフリー素材のイラストに替える（素材サイトの利用規約を確認する）
- 犬の動きはゆっくりにする（目が疲れない、画面がチカチカしない）。動きは1回だけで、ずっと動き続けない
- 文字や時刻のじゃまにならないよう、犬は画面の下か、道のりの列の中だけに出す

Day8 のあとに足すこと:

- 歩く量の目安を、乗り換え候補の中にふつうの文で出す。例: 「病院まで歩く: 約2分（約200歩）」（`data/places.json` の歩く分数 × 100歩）
- 犬の名前を自分でつけられるようにする（JSON に保存する）

5. かかりつけ医を登録する画面
目的: 一関・水沢の個人病院でも「受付に間に合うか」まで出せるようにする

進める順番:

1. Day8 まで: 病院の選択肢に「一関駅のまわりの医院」などのエリアを出す（駅に着く時刻と帰りの時刻まで出す）
2. Day8 のあと: この画面を作り、かかりつけ医を1つだけ登録できるようにする
3. 使ってもらって問題がなければ、3つまで登録できるようにする

部品と並び順:

タイトル文字: 「かかりつけのお医者さんを教えてください」

入力欄（縦並び、文字は大きく）:

「医院の名前」（例: 〇〇内科）

「どのあたりですか」ボタン: 「一関駅のまわり」「山目のあたり」「水沢駅のまわり」

「駅（バス停）から歩いて何分ですか」ボタン: 「5分」「10分」「15分」「タクシーで行く」

「午前の受付は何時までですか」ボタン: 「11:00」「11:30」「12:00」「12:30」

「お休みの曜日」ボタン（いくつでも選べる）: 「月」「火」「水」「木」「金」「土」

「電話番号」（数字だけ）

ボタン: 「登録する」

登録したあと:

- 病院の選択肢の一番上に「かかりつけ: 〇〇内科」が出る
- 結果画面では「駅に着く時刻 + 歩く時間」と受付の締め切りを比べて、「受付に間に合います」「間に合いません」を出す
- お休みの曜日を選んだ日には「この日はお休みです」と出す

作り方のメモ:

- 入力は家族が代わりにしてもよい前提にする。キーボードで打つのは名前と電話番号だけにして、あとはボタンで選ぶ
- 登録した内容は JSON ファイルに保存する（データベースは使わない）
