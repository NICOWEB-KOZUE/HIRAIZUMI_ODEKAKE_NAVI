- 水・土・日は運行なし。祝日と 12月29日〜1月3日も運休
- 月・火は午後便がジョイスに寄る（買い物向け）。木・金は町民温泉に寄る（通院・温泉向け）
- 各ルート、1日に午前便1本と午後便1本だけ
- ルートと曜日の対応は、PDF の表の並びと停留所名（16区公民館、18区公民館など）から判断した。町に確認しておく

## 乗り換え候補の例

長島南北ルート沿いに住む人が、金曜の午前に一関の病院へ行く場合:

- JR で行く:
  - 行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:20 → 一ノ関 10:27
  - 帰り: 一ノ関 12:46 → 平泉 12:54 → 平泉駅 13:35 のバス → 長島体育館 13:49
  - 一関にいられる時間: 約2時間20分
  - 運賃（65歳以上）: 行き 410円（バス200円 + JR 210円）、帰り 410円、往復 820円
- 路線バスで行く:
  - 行き: 長島体育館 9:16 → 平泉駅 9:33 → 一関平泉線 10:18 → 一関駅前 10:43
  - 帰り: 一関駅前 12:30 → 平泉駅前 12:55 → 平泉駅 13:35 のバス → 長島体育館 13:49
  - 一関にいられる時間: 約1時間45分
  - 運賃（65歳以上）: 行き 570円（バス200円 + 路線バス370円）、帰り 570円、往復 1,140円
  - 山目駅前など、一関駅より手前のバス停で乗り降りできる

月・火曜は、午後便が平泉駅を 11:37〜11:38 に出るため、一関で用事を済ませてバスで帰るのは難しい。帰りはタクシーを候補に出す。

### 病院まで行く場合（金曜・長島南北ルート・長島体育館から）

磐井病院（一関）:

- 行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:20 → 一ノ関 10:27 → 循環線（左回り）11:20 → 磐井・南光病院 11:32
- 帰り: 磐井・南光病院 12:10 → 一関駅前 12:20 → JR 12:46 → 平泉 12:54 → 平泉駅 13:35 のバス → 長島体育館 13:49
- 病院にいられる時間が約40分しかない。一ノ関駅からタクシーを使う候補も出す

岩手病院（一関、受付は 11:00 まで）:

- 行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:20 → 一ノ関 10:27 → 循環線（右回り）10:40 → 岩手病院前 10:53
- 受付締め切りの7分前に着く。バスが遅れたときに備えてタクシーも候補に出す
- 帰り: 岩手病院前 11:46 → 一関駅前 12:00 → JR 12:46 → 平泉 12:54 → 平泉駅 13:35 のバス → 長島体育館 13:49

胆沢病院（水沢、受付は 11:00 まで）:

- 行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:23 → 水沢 10:39 → 水岩線 11:22 → 胆沢病院 11:30
- 11:30 着では受付に間に合わない。水沢駅からタクシー（約2.7km）なら 11:00 前に着ける見込み
- 帰り: 胆沢病院 12:22 → 水沢駅前 12:30 → JR 13:06 → 平泉 13:21 → 平泉駅 13:35 のバス → 長島体育館 13:49

水沢病院（水沢、受付は 11:30 まで。水・木は 11:00 までの科あり）:

- 行き: 長島体育館 9:16 → 平泉駅 9:33 → JR 10:23 → 水沢 10:39 → 水岩線 11:20 → 水沢病院前 11:25
- 受付締め切りの直前に着く。間に合わない場合に備えてタクシーも候補に出す
- 帰り: 水沢病院前 12:37 → 水沢駅前 12:42 → JR 13:06 → 平泉 13:21 → 平泉駅 13:35 のバス → 長島体育館 13:49

アプリでは、病院に着く時刻が受付締め切りを過ぎる候補には「受付に間に合いません」と出し、タクシーの候補を上に出す。
