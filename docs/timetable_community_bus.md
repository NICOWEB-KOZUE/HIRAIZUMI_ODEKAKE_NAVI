# コミュニティバス 全バス停の時刻

出典: 平泉町コミュニティバス利用ガイド（令和7年10月版） `docs/sources/community_bus_guide.pdf`

確認日: 2026-10-14

## 読み方

- どの便も「役場・平泉駅など町の中心 → 地区のバス停をひと回り → 平泉駅・役場など町の中心」の順に走る
- 地区から町の中心へ行くときは、家の近くのバス停から乗って「終わり」の平泉駅や役場で降りる
- 町の中心から家へ帰るときは、「始まり」の平泉駅や役場から乗って家の近くのバス停で降りる
- 水・土・日・祝日、12月29日〜1月3日は運休
- ルートと曜日の対応は、PDF の表の並びと停留所名から判断した。町に確認しておく
- 「町民温泉」は悠久の湯 平泉温泉のことと考えている。町に確認しておく
- 「大平」は平泉ルートと長島東西ルートの両方にある。同じ場所かどうか町に確認しておく
